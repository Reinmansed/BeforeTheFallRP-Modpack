# Before The Fall RP Modpack

Official modpack manifest repository for **Before The Fall RP**.

## Game profile
- Minecraft: 1.20.1
- Forge: 47.4.0

## Files
- `manifest.json` — pack version and compatibility metadata.
- `mods.json` — CurseForge project/file identifiers for the client mods.
- `server.json` — multiplayer server entry.

## Updating the pack
Update the manifest and mod list when publishing a new pack version. The launcher checks the raw GitHub manifest on startup.

## CurseForge
Mods are identified by CurseForge project and file IDs. The launcher should resolve and download files through the supported CurseForge distribution/API flow. Do not commit API keys or private credentials to this public repository.

## Status
Initial repository scaffold. The mod list and server address are intentionally empty until confirmed by the pack owner.
